# Markpad Native v2.0 — The VLC of Text Files

> **Blazing-Fast • 100% Offline • Zero Telemetry • 7 Languages • Free Forever**

Markpad Native is an open-source, high-performance desktop editor and multi-format text utility built with **Rust**, **Tauri v2**, **Svelte 5**, and **CodeMirror 6**.

---

## 🚀 Key Highlights

1. **Instant Cold Startup**: Launches in under 120ms with sub-30MB memory footprint.
2. **The "VLC" Philosophy**: Open, parse, format, and inspect almost any text or structured data file you encounter without heavy IDE overhead.
3. **True Cross-Window Tabs**: Tear off tabs into new windows or drag tabs smoothly between existing windows with native cursor hit-testing and insertion preview.
4. **Interactive Specialized Viewers**:
   - **Markdown Live Preview**: Full GFM, tables, syntax-highlighted code blocks, math, and checklists.
   - **JSON Tree Viewer**: Collapsible interactive tree with search and formatting.
   - **Data Table Viewer**: Sort, filter, and page large CSV and TSV spreadsheets.
   - **Office & PDF Reader**: Native offline viewing of Word (.docx), Excel (.xlsx), and PDF documents.
   - **Web Preview**: Instant sandboxed rendering of HTML and SVG vector art.
   - **Key-Value / INI Inspector**: Structured view of `.env`, `.ini`, `.toml`, and `.conf` configs.
   - **Log Filter**: Fast regex and level filtering (INFO, WARN, ERROR) for `.log` files.
5. **Standalone Export**: Export any document to standalone HTML, PDF print stream, or formatted clipboard content with 1 click.
6. **Global Reach**: Fully localized into 7 languages (English, Russian, Uzbek, Chinese, Korean, Japanese, and Spanish).

## ⌨️ Keyboard Shortcuts Reference

| Shortcut | Action | Scope |
| :--- | :--- | :--- |
| `Ctrl + N` | New Tab | Global |
| `Ctrl + O` | Open File Dialog | Global |
| `Ctrl + S` | Save Current File | Editor |
| `Ctrl + Shift + S` | Save As... | Global |
| `Ctrl + E` | Export Dialog (HTML / PDF / Clipboard) | Global |
| `Ctrl + R` | Recent Files Switcher | Global |
| `Ctrl + F` | Search & Replace Panel | Editor / Viewers |
| `Ctrl + W` | Close Active Tab | TabBar |
